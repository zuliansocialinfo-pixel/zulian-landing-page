## Method
Google Search guidance favors useful people-first content, descriptive unique titles, crawlable links and words people actually use to find the content. This map therefore assigns one primary intent cluster per route instead of stuffing all terms into Home.

No Keyword Planner / paid volume dataset was available in this run. The phrases below are semantic/search-intent candidates grounded in observed SERP language, official procurement terminology and Zulian's real offer. They must not be presented as measured-volume keywords.

## Route: /progetti-finanziati-pa.html
Primary buyer intent: company/professional needs a supplier quote for a funded project OR public body needs a digital-services supplier/offering.

Primary candidates:
- preventivo sito web per bando
- preventivo software per bando
- preventivo per progetto finanziato
- digitalizzazione aziendale bando
- fornitore servizi digitali PA
- siti web per enti pubblici
- sviluppo software pubblica amministrazione
- servizi digitali pubblica amministrazione
- offerta tecnica servizi digitali
- affidamento diretto servizi digitali

Supporting official vocabulary:
- affidamento diretto
- servizi e forniture
- sviluppo e gestione applicazioni software
- MePA / Acquisti in Rete PA
- Linee guida di design per siti internet e servizi digitali della PA

Public-copy boundary:
- never claim MePA registration unless verified;
- never promise eligibility, financing or award;
- distinguish funded-project quote from public procurement;
- avoid hard-coding procurement thresholds into evergreen marketing copy unless versioned and maintained.

## Search architecture rule
